# Mascot Lunch Departures

Spin-the-wheel lunch picker for Qantas HQ, 10 Bourke Rd, Mascot.
Pick a mood, set budget/time/group/walk limits, spin, and copy the result into the lunch chat.

## Updating places

All the places live in `places.js`. Edit it on GitHub (pencil icon), commit, and GitHub Pages republishes in about a minute.
The field guide is at the top of that file.

## Hosting

Served by GitHub Pages from the `main` branch root. No build step: it's one HTML file plus `places.js`.
